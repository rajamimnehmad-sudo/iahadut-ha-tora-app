Política de privacidad de Iahadut HaTora

Última actualización: 3 de septiembre de 2026

Esta política explica cómo Yejiel Nehmad gestiona la información utilizada por la aplicación Iahadut HaTora, operada desde Argentina.

Información que utiliza la aplicación

La aplicación puede utilizar identificadores técnicos anónimos, datos de diagnóstico y eventos de uso (por ejemplo, búsquedas y apertura de productos) para mejorar el catálogo y conocer qué funciones se utilizan. También puede utilizar un token técnico del dispositivo para enviar notificaciones push sobre actualizaciones del catálogo.

Los productos guardados y búsquedas recientes se almacenan localmente en el dispositivo. La aplicación no solicita nombre, documento, ubicación precisa, contactos ni información de pago.

Servicios de terceros

Para analítica, autenticación anónima, almacenamiento de métricas agregadas y notificaciones push se utilizan servicios de Firebase y Google. Estos proveedores procesan la información conforme a sus propias políticas y medidas de seguridad.

Uso y conservación

La información se utiliza únicamente para operar, mantener, medir y mejorar la aplicación, mostrar productos populares de forma agregada y enviar avisos solicitados por el usuario. No vendemos información personal ni la usamos para publicidad personalizada.

Notificaciones

Las notificaciones son opcionales. El usuario puede autorizarlas o desactivarlas desde los permisos del dispositivo.

Contacto

Para consultas sobre privacidad o solicitudes relacionadas con estos datos, escribí a ramnehmad@gmail.com.
